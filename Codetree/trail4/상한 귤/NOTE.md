## 한 줄 인사이트

처음부터 상한 귤을 모두 거리 0으로 큐에 넣으면, 각 귤이 가장 가까운 상한 귤로부터 영향을 받는 시간을 한 번의 BFS로 구할 수 있다.

## 상태와 출력

입력 `grid`와 결과 `map`을 분리한다. `grid`는 귤의 원래 상태를 유지하고, `map`에는 상하는 시간을 기록한다.

| 입력 상태 | 의미 | 결과 초기값 |
|---|---|---|
| 0 | 귤이 없는 칸 | -1 |
| 1 | 아직 상하지 않은 귤 | -2 |
| 2 | 처음부터 상한 귤 | BFS에서 0 기록 |

BFS가 끝난 뒤에도 -2인 칸은 어떤 시작점에서도 도달하지 못한 귤이다.

## 제출 코드의 접근

1. 결과 배열을 모두 -1로 초기화한다.
2. 정상 귤의 결과는 -2로 바꾼다.
3. 모든 상한 귤을 `Node(row, col, 0)`으로 같은 큐에 넣는다.
4. 큐에서 꺼낸 칸을 처음 방문한 경우 시간을 기록한다.
5. 상하좌우의 정상 귤을 `시간 + 1`로 큐에 넣는다.

여러 시작점이 같은 큐를 사용하므로 시간 0인 칸들이 먼저 처리되고, 그다음 시간 1, 시간 2 순서로 처리된다. 따라서 어떤 칸을 처음 처리했을 때의 시간이 모든 시작점 중 최소 도달 시간이다.

각 상한 귤마다 BFS를 따로 실행하면 같은 격자를 반복 탐색하게 된다. 다중 시작점 BFS는 이 탐색을 한 번으로 합친다.

## 방문 처리 위치

현재 코드는 큐에서 꺼낼 때 `visited`를 표시한다. 같은 칸이 여러 이웃에 의해 큐에 중복 삽입될 수 있지만, 이미 방문한 노드는 즉시 건너뛰므로 이웃 확장은 한 번만 한다. 격자의 차수가 최대 4이므로 시간과 공간의 점근적 복잡도는 여전히 O(N²)이다.

큐에 넣을 때 방문 표시하면 중복 삽입도 막을 수 있다. 이 방식에서는 처음 상한 귤을 넣을 때도 방문 표시를 함께 해야 한다.

## 복잡도와 주의점

- 격자 각 칸과 인접 관계를 일정 횟수 처리하므로 시간 O(N²)이다.
- 입력·결과·방문 배열과 큐에 O(N²) 공간을 사용한다.
- 귤이 없는 칸으로는 전파하지 않는다.
- 처음부터 상한 귤의 시간은 0이다.
- 모든 시작점을 탐색 전에 넣어야 동시에 전파되는 상황을 표현할 수 있다.
- 입력받은 K는 시작점 개수를 나타내지만, 현재 구현은 격자를 훑어 시작점을 직접 찾으므로 이후 별도로 사용하지 않는다.
