## 문제 요약

코드가 읽는 입력은 R행 C열 격자다. 1인 칸들이 상하좌우로 이어진 덩어리를 각각 하나의 섬으로 보고, 섬 사이를 같은 행 또는 열의 직선으로 연결한다. 연결 경로의 0인 칸 수를 비용으로 세며, 모든 섬을 연결할 수 없으면 -1을 출력한다. README는 이 문제를 Trail 6의 MST/Prim 문제로 분류한다. README에는 도로 길이 등의 상세 제한이 없어 여기서는 코드에서 확인되는 처리만 설명한다.

## 코드의 접근

1. 격자를 훑으며 DFS `cntIsland`로 각 1의 연결 요소에 번호를 붙이고, 섬별 좌표 목록을 만든다. 번호가 붙은 격자는 이후 도로 탐색에도 사용한다.
2. 서로 다른 섬의 칸 쌍을 확인한다. 두 칸이 같은 행 또는 열에 있을 때 네 방향으로 직선 탐색을 하며, 다른 섬이 먼저 나타나면 중단한다. 목적지에 도달하면 지나온 0의 개수 `dist`를 가중치로 하는 간선을 인접 리스트에 추가한다. 같은 섬 쌍의 간선이 여러 개 생길 수 있다.
3. 1번 섬을 비용 0으로 우선순위 큐에 넣고 프림 알고리즘을 실행한다. 가장 싼 후보 간선의 목적지가 아직 선택되지 않았다면 비용을 합산하고 그 섬의 간선을 큐에 넣는다. 선택한 섬 수가 전체 섬 수에 못 미치면 -1로 바꾼다.

## 핵심 원리

DFS가 서로 연결된 1의 영역을 하나의 정점으로 압축한다. 직선 탐색이 만든 간선은 코드가 허용하는 섬 사이 연결 후보와 그 비용을 나타낸다. 프림 알고리즘은 현재 선택한 섬 집합에서 바깥 섬으로 나가는 최소 비용 간선을 반복해서 택하므로, 연결 가능한 후보 그래프의 최소 신장 트리 비용을 구한다. 동일한 섬 쌍의 여러 간선을 남겨 두어도 우선순위 큐가 저렴한 후보부터 처리하고 이미 선택한 섬은 건너뛴다.

## 커밋에서 확인한 변경과 주의점

확인한 기간에는 한 번의 [Passed] 제출로 README와 Java 풀이가 함께 추가됐다. 별도의 수정 커밋은 확인되지 않는다. 복습할 때는 섬 번호를 격자에 기록한 뒤 0만 거리로 세는 점, 중간에 다른 섬이 있으면 간선을 만들지 않는 점, 큐가 빌려도 모든 섬을 고르지 못하면 -1을 출력하는 점을 확인한다. 코드에는 대체 인접 행렬 구현이 주석으로 남아 있지만 실제 실행은 인접 리스트를 사용한다.

## 복잡도

R·C는 격자 크기, A는 1인 칸 수, D는 max(R, C), E는 생성된 후보 간선 수다. 섬 찾기는 O(RC)이다. 모든 섬의 칸 쌍을 훑고 정렬된 쌍마다 최대 D칸을 탐색하므로 상한은 O(A²D)이다. 프림의 큐 작업은 O(E log E)이고, 저장 공간은 격자·방문 배열·좌표 목록과 간선을 합쳐 O(RC + E)이다. 실제 간선 수에는 같은 섬 쌍의 중복 후보도 포함된다.

## 한 줄 인사이트

격자의 연결 요소를 정점으로 압축하고 가능한 직선 연결을 간선으로 만들면, 전체 연결 비용 문제를 MST로 풀 수 있다.
