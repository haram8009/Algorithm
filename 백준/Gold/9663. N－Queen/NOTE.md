## 한 줄 인사이트

한 행에 퀸 하나씩 놓으면 행 충돌은 구조적으로 사라지고, 이전 퀸과 충돌하는 선택만 가지치기하면 된다.

## 문제 요약

N×N 체스판에 퀸 N개를 서로 공격하지 못하게 놓는 경우의 수를 구한다. 퀸은 같은 행, 같은 열, 같은 대각선의 다른 퀸을 공격한다.

## 제출 코드의 탐색

`dfs(depth)`는 `depth`번 행에 퀸을 놓는 단계다. 현재 행의 모든 열을 후보로 보고 `available(depth, col)`이 참인 위치에만 퀸을 놓는다.

1. `map[depth][col] = true`로 선택한다.
2. `dfs(depth + 1)`로 다음 행을 탐색한다.
3. 돌아오면 `false`로 복구한다.
4. `depth == n`이면 N개 배치에 성공했으므로 정답을 1 증가시킨다.

각 행을 정확히 한 번 처리하기 때문에 같은 배치를 퀸을 놓는 순서만 바꾸어 중복 계산하지 않는다.

`available`은 후보 위치에서 8방향으로 끝까지 이동하며 퀸을 찾는다. 현재 행과 아래쪽 행에는 아직 퀸이 없으므로, 실제로 필요한 검사는 위쪽 열과 위쪽 두 대각선이다.

## 열과 대각선을 O(1)에 확인하는 방법

이미 놓인 퀸들의 공격선을 배열에 기록하면 각 방향의 칸을 다시 훑을 필요가 없다.

| 검사 대상 | 배열 인덱스 | 같은 선인 이유 |
|---|---|---|
| 열 | `col` | 같은 열은 열 번호가 같다 |
| 오른쪽 아래로 향하는 대각선 | `row - col + n - 1` | 행과 열이 함께 증가하여 차가 일정하다 |
| 왼쪽 아래로 향하는 대각선 | `row + col` | 행 증가와 열 감소가 상쇄되어 합이 일정하다 |

예를 들어 `(0, 1)`, `(1, 2)`, `(2, 3)`은 모두 `row - col = -1`이다. 이 대각선에 퀸이 하나라도 있으면 대응하는 배열 원소 하나를 `true`로 기록한다. 따라서 배열 한 칸을 읽는 것으로 그 대각선 전체의 점유 여부를 알 수 있다.

열 배열은 길이 N, 두 대각선 배열은 각각 길이 `2N-1`이면 된다. 재귀 호출 전 세 값을 `true`, 돌아온 뒤 `false`로 복구한다.

## 복잡도

현재 코드는 후보 하나의 충돌 검사에 O(N), 행 하나에서 N개 열을 시도한다. 열 중복만 고려해도 유효한 부분 배치는 순열 형태로 제한되므로, 보수적인 시간 상한은 O(N²·N!)로 볼 수 있다. 대각선 가지치기로 실제 탐색량은 줄어든다.

체스판은 O(N²), 재귀 호출 스택은 O(N)을 사용하므로 전체 공간은 O(N²)이다. 점유 배열 방식으로 바꾸면 충돌 검사는 O(1), 공간은 O(N)으로 줄어든다.

## 주의점

- 선택한 위치를 재귀에서 돌아온 뒤 반드시 복구해야 한다.
- 대각선의 `row - col`은 음수가 될 수 있으므로 `n - 1`을 더한다.
- 현재 제출 코드는 8방향을 직접 검사해 정답을 구하며, 점유 배열은 별도의 최적화 아이디어다.
