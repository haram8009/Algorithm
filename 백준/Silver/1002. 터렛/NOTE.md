## 한 줄 인사이트

두 위치에서 주어진 거리만큼 떨어진 점은 두 원의 교점이므로 중심 거리와 반지름의 합·차를 비교하면 된다.

## 문제와 접근

각 터렛을 원의 중심으로, 측정한 거리를 반지름으로 보면 적이 있을 수 있는 위치는 두 원 위에 동시에 놓이는 점이다. 두 원이 같으면 무한대, 접하면 1개, 두 점에서 만나면 2개, 만나지 않으면 0개이다.

제곱근을 구하지 않고 다음 세 값을 비교한다. 코드의 `d`는 중심 거리 자체가 아니라 중심 거리의 제곱이다.

```java
int d = (x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1);
int sr = (r1 + r2) * (r1 + r2);
int dr = (r1 - r2) * (r1 - r2);
```

## 조건 분기

| 조건 | 두 원의 관계 | 답 |
|---|---|---:|
| `d == 0 && r1 == r2` | 완전히 같은 원 | -1 |
| `d == sr` | 외접 | 1 |
| `d == dr && d != 0` | 내접 | 1 |
| `dr < d && d < sr` | 두 점에서 만남 | 2 |
| 나머지 | 떨어져 있거나, 만나지 않고 포함됨 | 0 |

먼저 같은 원인지 확인해야 한다. 중심이 같고 반지름도 같으면 `d == dr == 0`이지만 내접이 아니라 교점이 무한대이기 때문이다. 중심은 같고 반지름이 다르면 교점은 없다.

`answer`를 0으로 초기화했으므로 위 조건에 해당하지 않는 경우에는 별도의 대입 없이 0을 출력한다.

## 복잡도

- 시간: 케이스당 O(1), 전체 O(T)
- 추가 공간: O(1)

## 주의점과 확인 예시

- 반지름의 차는 절댓값을 취하지 않아도 제곱하면 같은 결과가 된다.
- 거리와 반지름은 음수가 아니므로 제곱한 값 사이의 대소 관계도 유지된다.
- 좌표 범위가 더 큰 문제에서는 제곱 전 `long`으로 변환해야 오버플로를 막을 수 있다.
- 중심 `(0, 0)`, `(2, 0)`에 반지름이 각각 1이면 외접하여 답은 1이다.
- 중심 `(0, 0)`, `(1, 0)`에 반지름이 각각 2이면 두 점에서 만나 답은 2이다.
- 중심과 반지름이 모두 같으면 답은 -1이다.
